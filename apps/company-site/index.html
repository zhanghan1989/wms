Product / 产品能力

从分散报告，到可用信息。

减少重复下载和合并报表的工作，以店铺为边界保存授权与同步状态。系统面向内部运营与获邀客户，不提供消费者购物服务。

01 / AUTHORIZATION

店铺独立授权

每个 Amazon 销售账户单独完成 OAuth 授权，刷新令牌加密保存，连接状态可单独停用或重新授权。

02 / ORDERS

FBA 与 FBM 订单

按照 Amazon 履约和卖家自配送渠道分别同步订单及商品明细，支持销售数量与状态分析。

03 / INVENTORY

FBA 库存

同步可售、在途、预留及不可售库存，为补货和仓储协同提供统一参考。

04 / DASHBOARD

销售与库存看板

只有全部启用店铺完成同步后才生成汇总快照，避免用不完整数据代表整体经营情况。

05 / WAREHOUSE

海外仓协同

结合现有 SKU、箱号、入库、出库和补货流程，减少跨系统重复录入。

06 / AUDIT

状态与审计记录

保留授权时间、同步运行、错误信息和重要操作记录，帮助运营人员定位异常。

Security / 数据与安全

只处理完成服务所需的数据。

当前版本计划使用非受限角色完成订单统计与库存分析，不主动请求或保存买家姓名、地址、电话等受限个人信息。若未来功能范围发生变化，将在启用前更新说明并完成所需审核。

  • HTTPS 加密传输，授权刷新令牌采用 AES-256-GCM 加密保存
  • 用户按职责分配权限，管理操作保留审计记录
  • 店铺连接可以停用，用户可以申请撤销授权和删除数据
  • 仅为提供已授权服务使用数据，不出售 Amazon 信息
