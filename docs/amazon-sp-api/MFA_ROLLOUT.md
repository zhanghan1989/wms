# 生产 MFA 与密码轮换上线步骤

当前生产环境有 18 个有效账号，尚未启用 MFA。Amazon Developer Profile 提交前应完成以下步骤并保存证据。

## 用户操作

1. 登录 `https://wms.fulangke.cn/`；
2. 进入个人资料，点击“设置 MFA”；
3. 用 Microsoft Authenticator、Google Authenticator 或其他 TOTP 认证器扫描二维码/录入密钥；
4. 在“6 位验证码”中填写认证器**当前显示且每 30 秒更新的数字**，不是短信验证码，也不是固定密码；
5. 验证启用后退出并重新登录，确认登录页可用相同认证器的新验证码登录；
6. 按提示把密码更新为至少 12 位、含大小写字母、数字和特殊字符的唯一密码。

不要截图、复制到聊天工具或多人共用 MFA 设置密钥。手机时间必须启用自动同步。

## 管理员上线顺序

- [ ] 先由主管理员完成 MFA 设置并验证重新登录；
- [ ] 通知其他 17 个有效账号逐一完成设置；
- [ ] 导出仅含用户名、状态、`mfaEnabledAt`、`passwordChangedAt` 的完成清单；
- [ ] 确认 18 个有效账号全部完成；
- [ ] 在生产 `.env` 设置 `AUTH_REQUIRE_MFA=true`；
- [ ] 在生产 `.env` 设置 `AUTH_REQUIRE_PASSWORD_ROTATION=true`；
- [ ] 只重建 API 容器，不重建数据库；
- [ ] 使用管理员和普通用户各完成一次登录验证；
- [ ] 将脱敏清单、配置核验和测试截图归档到申请证据中。

如果提前启用强制开关，未设置 MFA 的账号仍可用原密码进入专用设置流程，但在完成 MFA 前无法访问其他业务接口。建议仍按上述顺序减少生产使用中断。
