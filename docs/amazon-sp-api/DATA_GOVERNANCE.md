# Fulangke WMS · Amazon 数据治理与第三方登记表

版本：2026-08-05
复审：每 6 个月及新增数据源/接收方前

## 1. 数据清单与保留

| 数据 | 来源 | 用途 | 首期保留策略 |
| --- | --- | --- | --- |
| Seller ID、Marketplace、授权状态 | Amazon OAuth | 店铺识别、连接管理 | 授权有效期及终止后必要审计期 |
| 加密 Refresh Token | Amazon LWA | 换取短期 Access Token | 撤销/终止后立即删除 |
| 订单号、状态、履约渠道、SKU、ASIN、数量、金额 | Amazon Orders API | FBM/FBA 订单、销售分析、履约协同 | 最长 18 个月，之后删除或聚合匿名化 |
| FBA 库存 | Amazon FBA Inventory API | 库存和补货分析 | 当前值及必要历史快照，最长 18 个月 |
| 同步和安全日志 | WMS | 故障、安全调查和审计 | 原则上 12 个月；法律另有要求除外 |
| 买家姓名、地址、电话、邮箱 | 不在首期申请范围 | 无 | 不请求、不保存 |

删除必须覆盖主数据库、缓存、导出文件和可控备份。备份中的到期数据随备份轮换自然清除，恢复后必须重新执行删除任务。

## 2. 外部处理方/接收方

| 外部方 | 数据/权限 | 条件与限制 |
| --- | --- | --- |
| 阿里云 | ECS、磁盘、网络和备份承载的数据 | 仅用于基础设施托管；账号最小权限；中国大陆区域。 |
| GitHub | 源代码和 CI/CD 元数据 | 不上传 Amazon 业务数据、生产 `.env`、Refresh Token 或数据库备份。 |
| XIYA 业务系统 | 经授权用户选择交由其履约的订单运营信息、产品及物流状态 | 仅为明确的履约/物流用途；需完成保密、删除及事件通知约定；不得转作广告或转售。 |
| UOF 物流接口 | 运单号及查询所需标识 | 仅查询物流轨迹；不得传输 Amazon OAuth 凭证。 |

新增外部方之前必须记录：公司名称、服务、数据字段、存储国家/地区、保留期、分包方、安全控制、删除机制和事件通知时限。

## 3. 外部（非 Amazon）数据来源

- WMS 授权用户手工录入或上传的 SKU、订单、库存和仓储数据；
- XIYA 产品、订单和物流接口；
- UOF 物流轨迹接口；
- Yamato 发货及面单业务文件；
- 阿里云基础设施日志和 WMS 自身生成的审计/同步日志。

外部数据不得与 Amazon 信息组合用于广告画像、信用评估、数据出售或与获准服务无关的用途。

## 4. 用户请求与终止

授权组织可请求访问、更正、导出、删除或停用其店铺连接。处理前必须验证请求人代表相应 Seller 的权限。撤销授权或终止服务后：

1. 立即停止同步并删除 Refresh Token；
2. 在 30 天内删除或不可逆匿名化非必要 Amazon 数据；
3. 通知适用的外部处理方执行删除；
4. 保留删除记录，但不得在记录中保存已删除的敏感内容。
