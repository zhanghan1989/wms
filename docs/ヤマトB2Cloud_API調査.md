# ヤマト B2クラウド API 調査メモ

更新日: 2026-04-14

## 公开资料确认到的能力

- B2クラウド API 支持两种模式:
  - 画面 API
  - 画面なし API
- 公开简版规约明确写到:
  - 可从客户系统注册出荷数据
  - 可发起送り状发行
  - 可确认印刷状态
  - 可下载 PDF
- 认证方式:
  - 使用 `Accesstoken`
  - 通过 HTTP Header 传递
- 通信方式:
  - HTTPS
  - GET / POST / PUT
  - 数据以 ATOM 表达，转换为 JSON 或 MessagePack

## 当前项目已落地的部分

- 海外仓订单处理一览支持:
  - 勾选批量生成ヤマト导入 Excel
  - 扫码订单号后，按单生成ヤマト导入 Excel
- 乐天 / 亚马逊共用同一套ヤマト字段映射
- 电话字段在导出前会移除 `-` 等分隔符

## 仍缺少的官方接入资料

公开页面只有简版规约，没有公开字段级接口规范。要做真正的 API 出面单，还需要ヤマト提供至少以下资料:

- B2クラウド API 详细接口规格书
- 本番或検証环境的 API Base URL
- `Accesstoken`
- 画面 API / 画面なし API 具体要使用哪一种
- 出荷数据字段名与必填项定义
- PDF 下载与印刷状态确认的具体接口

## 当前建议

- 现阶段先用扫码直出 Excel 保证现场流程可跑
- 拿到ヤマト正式接口资料后，把现有字段映射直接接到 API adapter 即可
