# Xiya 主表可用库存接口文档

更新日期：2026-04-23

本文档用于提供给 Xiya 系统，对接 WMS 的“当前主表产品可用库存”查询接口。

## 1. 对接目标

Xiya 可以通过本接口获取 WMS 当前主表中库存数大于 0 的产品列表。

本接口只允许 Xiya 读取库存数据，不能新增、修改或删除 WMS 库存。

接口返回字段：

- 产品 ID
- 产品名称
- 当前库存数

## 2. 基础信息

Base URL：

```text
http://8.134.176.116:3000/api
```

接口返回时间字段为 ISO 8601 字符串，例如：

```text
2026-04-23T08:30:00.000Z
```

## 3. 鉴权方式

本接口使用第三方 API Key 鉴权。

推荐使用请求头：

```http
x-api-key: YOUR_THIRD_PARTY_API_KEY
```

也支持 Query 参数：

```text
?apiKey=YOUR_THIRD_PARTY_API_KEY
```

## 4. 接口信息

```http
GET /api/master-products/available-stock
```

完整地址：

```text
http://8.134.176.116:3000/api/master-products/available-stock
```

## 5. 返回哪些产品

该接口只返回 WMS 产品主表中 `库存数 > 0` 的产品。

不会返回：

- 库存数为 0 的产品
- 库存数小于 0 的产品

排序规则：

- 库存数从大到小
- 库存数相同时按产品 ID 从小到大

## 6. 请求示例

```bash
curl -X GET "http://8.134.176.116:3000/api/master-products/available-stock" \
  -H "x-api-key: YOUR_THIRD_PARTY_API_KEY"
```

## 7. 成功响应

```json
{
  "exportedAt": "2026-04-23T08:30:00.000Z",
  "total": 2,
  "rows": [
    {
      "productId": "8736",
      "productName": "Evelyne伊芙琳 16/18 黑色 绸缎内胆包",
      "stockQty": 12
    },
    {
      "productId": "1088",
      "productName": "假产品ID-爱马仕饭盒包",
      "stockQty": 6
    }
  ]
}
```

## 8. 返回字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `exportedAt` | string | 本次查询时间 |
| `total` | number | 本次返回产品数量 |
| `rows` | array | 产品列表 |
| `rows[].productId` | string | WMS 产品 ID |
| `rows[].productName` | string/null | 产品名称 |
| `rows[].stockQty` | number | 当前主表库存数 |

## 9. 失败响应示例

### 9.1 API Key 错误

```json
{
  "statusCode": 401,
  "message": "第三方接口密钥无效",
  "error": "Unauthorized"
}
```

### 9.2 未配置第三方 API Key

```json
{
  "statusCode": 503,
  "message": "未配置第三方接口密钥",
  "error": "Service Unavailable"
}
```

## 10. 注意事项

- 本接口是只读接口，只支持 `GET` 查询。
- Xiya 只能通过该接口获取 WMS 当前库存，不能通过该接口修改库存。
- `stockQty` 是 WMS 主表当前库存数。
- 主表库存由箱内库存汇总而来，不建议外部系统自行覆盖。
- 如果 Xiya 需要判断某个产品能否走日本发，可以使用 `stockQty > 0` 作为判断依据。
- 该接口只读，不会修改 WMS 数据。
