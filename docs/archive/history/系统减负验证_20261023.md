# 系统减负验证记录（2026-10-23）

## 本轮范围

- Redis 改为可选服务，并从默认本地启动及发布流程移除显式启动。
- Compose 容器日志每份 10MB，保留 3 份。
- 乐天处理中心在浏览器后台暂停轮询。
- 看板库存商品每批读取 500 条，引用商品去重；快照连接仅选择必要字段，汇总后清空 SKU 映射。
- 备份检查合并并发扫描，备份创建期间跳过后台检查，并等待先前扫描完成；定时任务防止重叠。
- 构建阶段只复制必要源码和配置，排除本地数据及环境文件。
- 镜像导入限时 10 分钟；迁移在容器内限时 300 秒，30 秒后强制结束，不自动重复迁移。

- 官网页面检查、已跟踪文件密钥扫描、类型检查、应用构建通过。

- 没有执行部署、数据库迁移或生产容器操作，没有测量生产性能降幅。

## 发布时需要核验

- 在构建环境完成依赖审计、Docker 构建及 Compose 配置校验。
- 已存在的 Redis 容器不会因改为可选服务自动停止；先核实线上无外部使用者，再安排停止。
- 日志轮转配置需要容器重建后生效；MySQL 重建会有短暂中断，应安排窗口。
- 数据库迁移超时可能留下需要人工核查的迁移状态，应查看迁移日志后处理，避免盲目重跑。
- 看板仍需保留最终商品汇总集合，分页只减少读取过程的额外峰值，不是恒定内存处理。
- 上线后比较 API/MySQL 内存、看板耗时、同步峰值与镜像导入耗时。

原有未提交的乐天业务修改予以保留；完整测试是在包含这些修改的当前工作区执行。
