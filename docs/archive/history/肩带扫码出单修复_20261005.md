# 肩带扫码出单修复（2026-10-05）

## 操作规则

- 肩带成品码或本体码二选一，每件只扫一次。库存成品和现场组装允许使用相同的替代扫码方式，不要求一件扫两种码。
- 本体码对应多个订单时选择订单；同一订单内多个成品共用本体时选择本次成品。首次扫码在选定目标后只计入一次。
- 配件无单件码：显示组装总需求和拣货数量记录，人工清点、输入实点数量并确认。后端校验扫码记录中的成品、本体别名和总数量，以及配件确认数量。
- 面单括号内为包裹规格的材料总量（含库存成品内已装材料）；确认窗口的材料需求仅计算需要现场组装的部分。
- 正常打印、失败重试、补打独立处理。重复提交复用原任务；补打须选择原订单并确认，保留原快递单号和首次打印时间。正在执行的原任务不能直接作废后补打。
- 三种打印方式均在实际出纸确认后登记完成。打印代理提交成功只表示打印机已接受任务；尚未出纸时应先取消打印机内待打印任务，再确认未出纸并重试。
- 打印提交结果不明确时保留任务，人工核对，防止网络故障导致重复出单。
- PDF 优先按完整订单号唯一匹配；订单号缺失时要求产品及收件人唯一匹配。不唯一、同一页匹配多个订单、已有打印任务时均阻止替换。
- 打印任务保存操作员、实际扫描码及数量、配件确认数量、补打标记、提交及出纸确认记录。
