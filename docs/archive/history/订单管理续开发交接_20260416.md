# 订单管理续开发交接

更新日期：2026-04-16

本文档用于承接本轮“订单管理 / 海外仓拣货 / Yamato 面单 / 中国发切换 / 打印”相关开发，方便下次继续开发时快速回到上下文。

## 1. 本轮开发目标

本轮主要围绕下面这条业务链路落地：

1. 导入乐天 / 亚马逊订单。
2. 将当前有库存的订单聚合到“海外仓订单处理一览”。
3. 勾选订单后生成拣货批次。
4. 在批次详情里按产品聚合拣货，而不是按订单逐条拣货。
5. 拣货确认后扣减实际库存，并生成 Yamato Excel。
6. 将 Excel 上传到 Yamato B2Cloud，拿回批量 PDF。
7. 将批量 PDF 回传到 WMS，解析 PDF 页并回写运单号。
8. 仓库扫描贴在产品上的产品 ID，自动匹配对应 PDF 面单页并打印。
9. 无法海外仓发货的订单切到“中国订单处理一览”。

当前实现是基于“Excel + PDF 回传”的方案，不依赖 Yamato API。

## 2. 当前已经确定的业务规则

### 2.1 订单处理入口

- “订单处理”首页目前有 4 个入口：
- 乐天订单处理
- 亚马逊订单处理
- 海外仓订单处理
- 中国订单处理

其中：

- 海外仓订单处理：显示当前有库存、可走海外仓拣货的订单。
- 中国订单处理：显示系统无库存，或在拣货阶段被切换到中国发的订单。

### 2.2 海外仓批次流程

当前确定的标准流程如下：

1. 进入“海外仓订单处理一览”。
2. 勾选待处理订单。
3. 点击“批次生成”。
4. 进入“批次管理一览”，点击批次号进入批次详情。
5. 在批次详情中按产品 ID 聚合拣货。
6. 扫描产品 ID 完成拣货。
7. 点击“确认拣货并生成 Yamato Excel”。
8. 将导出的 Excel 上传到 Yamato B2Cloud。
9. 从 Yamato 下载批量 PDF，但先不打印。
10. 将 PDF 上传回 WMS。
11. WMS 解析每一页 PDF，绑定产品 / 订单 / 运单号。
12. 仓库扫描产品 ID，系统匹配对应页并打印面单。

### 2.3 中国发切换规则

这条规则已经在本轮确认并落地，后续不要再按旧逻辑理解：

- “切中国发”只在当前批次未确认时使用。
- 点击“切中国发”后，订单不会继续保留在当前批次中。
- 系统会把对应订单状态改为 `china_pending`。
- 同时把该订单从当前海外仓批次中删除。
- 删除后如果当前批次为空，批次会自动删除。
- 订单会出现在“中国订单处理一览”中，而不是回到海外仓批次列表里。

### 2.4 拣货扫码提示规则

目前扫码错误提示按下面规则处理：

- 如果扫到的产品 ID 不在当前批次中：提示“批次中不存在产品 xxx”。
- 如果该产品在当前批次中，但已全部完成拣货：提示“产品 xxx 已全部完成拣货”。

注意：

- 现在不会再显示“该产品已切中国发”的扫码提示。
- 因为业务上“切中国发”后，该订单已经被移出当前批次，不属于当前批次扫码范围。

## 4. 拣货逻辑当前实现

### 4.1 聚合维度

批次详情里的拣货清单，当前是按 `productId` 聚合的，而不是按订单聚合。

每个聚合产品显示：

- 货架号
- 箱号
- 该箱库存数
- 产品 ID
- 产品名称
- 在库数
- 应拣
- 已拣
- 剩余
- 操作

### 4.2 箱内拣货计划

当前货位展示规则：

- 如果某个产品分布在多个箱子中，优先从库存最少的箱子开始拣。
- 展示为多行：
  - 货架号
  - 箱号
  - `该箱库存数-拣货数`
- 例如：
  - `7-7`
  - `18-3`

### 4.3 库存扣减规则

点击“确认拣货并生成 Yamato Excel”后：

- 系统会按上面展示的拣货计划进行扣库存。
- 后端实际扣减时也已经按“箱内库存从小到大”的顺序处理，和页面展示保持一致。

### 4.4 拣货确认校验

确认拣货前，后端有两层校验：

1. 每个未切中国发的批次明细，必须 `actualQty === requestedQty`。
2. 再按产品汇总，校验“拣货产品与数量”和“订单需要产品与数量”完全一致。

如果不一致，会阻止继续生成 Yamato Excel。

## 5. Yamato 相关当前实现

### 5.1 当前方案

因为暂时没有 Yamato API，所以目前采用：

- WMS 导出 Yamato Excel
- 人工上传到 B2Cloud
- B2Cloud 生成并下载 PDF
- 再把 PDF 回传到 WMS

### 5.2 当前已实现能力

- 支持从海外仓批次生成 Yamato Excel。
- 支持上传 Yamato PDF。
- 支持解析 PDF 并拆页。
- 支持将 PDF 页与订单 / 产品 / 运单号绑定。
- PDF 解析成功时，已经会先把运单号写回订单数据。
- 扫描产品 ID 时，系统会定位到对应 PDF 页。
- 支持打印后回写打印状态。

### 5.3 打印方案现状

当前打印分为 3 种能力：

- 浏览器预览打印
- 直打到指定打印机
- 加入打印队列，由打印代理处理

但要注意：

- 真正打印的电脑不是开发这台 Mac。
- 因此生产使用应优先走打印代理方案。
- 产品主表中已经追加 `yamatoPrinterName`，可用于给产品配置目标打印机。
- 打印代理相关说明见 `docs/print-agent-setup.md`。

## 6. 中国订单处理当前现状

当前“中国订单处理一览”主要用于承接两类订单：

- 系统判断库存不足，无法进入海外仓订单处理的一览
- 海外仓拣货时，人工切换到中国发的订单

当前状态：

- 页面与订单聚合已具备。
- 海外仓切中国发后，订单能进入该列表。
- 但“中国发货”的完整出单、扣库存、物流回传流程尚未开发完成。
