# XYJG 对外接口统一文档

更新日期：2026-06-25

本文档涵盖 XYJG 系统对外提供的所有接口。多租户架构下，所有接口均需指定公司（通过 `company_name` 或 `company_code`）。

---

## 通用说明

### 公司标识（多租户隔离）

所有对外接口都需要指定要操作的公司，支持两种方式（二选一）：

| 参数 | 位置 | 优先级 | 说明 |
|------|------|--------|------|
| `company_name` | Query 参数 或 请求体字段 | **优先** | 公司名称，如 `"DGAZ"` |
| `company_code` | Query 参数 或 请求体字段 | 备选 | 公司编码，如 `"CO260620123"` |

> 系统优先使用 `company_name` 查找公司。如果 `company_name` 为空，才会使用 `company_code`。两者至少传一个。

### 认证方式

| 接口类型 | 认证方式 | 说明 |
|---------|---------|------|
| 数据导出接口（GET） | API Key | 通过 Header `x-api-key` 或 Query 参数 `apiKey` 传递 |
| 外部推送接口（POST） | 无需认证 | 通过请求体中的 `company_name`/`company_code` 标识公司 |

**导出接口 API Key**：由双方通过安全渠道单独提供，不写入接口文档。

### 统一响应格式

```json
{
  "code": 0,
  "message": "提示信息",
  "data": {}
}
```

| 字段 | 说明 |
|------|------|
| `code` | 业务状态码，`0` = 成功，非0 = 失败 |
| `message` | 提示信息 |
| `data` | 数据载体 |

## 接口一：物流单导出

### 基本信息

| 项目 | 说明 |
|------|------|
| **接口地址** | `GET /api/external/logistics/rakuten` |
| **接口文档** | `GET /api/external/logistics/rakuten/info`（无需密钥） |
| **认证方式** | API Key |
| **功能** | 导出指定公司、指定店铺、指定天数范围内的物流运单数据 |

### 请求参数

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `company_name` | String | **是**（二选一） | - | 公司名称（优先使用） |
| `company_code` | String | **是**（二选一） | - | 公司编码（`company_name` 为空时使用） |
| `apiKey` | String | 是 | - | API 密钥，可通过 Header `x-api-key` 或 Query 参数传递 |
| `storeName` | String | 否 | `DGAZ乐天日本` | 店铺名称，支持多店铺（逗号分隔）和 `all` 关键字 |
| `days` | Integer | 否 | `3` | 查询最近 N 天内的物流单数据 |

### storeName 参数说明

| 格式 | 示例 | 说明 |
|------|------|------|
| 单个店铺名 | `DGAZ乐天日本` | 查询指定店铺的运单 |
| 逗号分隔多店铺 | `DGAZ乐天日本,DGAZ亚马逊日本站` | 一次查询多个店铺 |
| `all` 或 `*` | `all` | 查询所有店铺 |
| 不传 | - | 默认查询 `DGAZ乐天日本` |

### 请求示例

```bash
# 使用公司名称（推荐）
curl -X GET "http://103.236.55.93/api/external/logistics/rakuten?company_name=DGAZ&storeName=DGAZ乐天日本&days=7" \
  -H "x-api-key: YOUR_EXPORT_API_KEY"

# 查询所有店铺
curl -X GET "http://103.236.55.93/api/external/logistics/rakuten?company_name=DGAZ&storeName=all&days=7" \
  -H "x-api-key: YOUR_EXPORT_API_KEY"

# 使用公司编码（备选）
curl -X GET "http://103.236.55.93/api/external/logistics/rakuten?company_code=CO260620123&storeName=DGAZ乐天日本&days=7" \
  -H "x-api-key: YOUR_EXPORT_API_KEY"
```

### 成功响应

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "exportedAt": "2026-06-25T15:30:00+08:00",
    "total": 25,
    "rows": [
      {
        "id": 1001,
        "logistics_order_id": "YT202604200001",
        "tracking_number": "YT1234567890123",
        "sales_order_id": "284518-20260420-0001",
        "store_name": "DGAZ乐天日本",
        "shipping_method": "云途标准快递",
        "created_at": "2026-04-20T08:15:30+08:00",
        "logistics_status": "已发货"
      }
    ]
  }
}
```

### 返回字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `exportedAt` | String | 数据导出时间 |
| `total` | Integer | 返回的运单记录总数 |
| `rows[].id` | Integer | 物流记录内部 ID |
| `rows[].logistics_order_id` | String | 物流订单编号（系统内部） |
| `rows[].tracking_number` | String | 快递运单号（跟踪号） |
| `rows[].sales_order_id` | String | 关联的销售订单号 |
| `rows[].store_name` | String | 所属店铺名称 |
| `rows[].shipping_method` | String | 运输方式名称 |
| `rows[].created_at` | String | 物流记录创建时间 |
| `rows[].logistics_status` | String | 物流状态 |

> 仅返回 `logistics_order_id` 不为空的记录（已成功申请到运单号的物流单）。

## 接口二：产品信息导出

### 基本信息

| 项目 | 说明 |
|------|------|
| **接口地址** | `GET /api/external/products` |
| **接口文档** | `GET /api/external/products/info`（无需密钥） |
| **认证方式** | API Key |
| **功能** | 导出指定公司最近有更新的产品信息（含属性） |

### 请求参数

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `company_name` | String | **是**（二选一） | - | 公司名称（优先使用） |
| `company_code` | String | **是**（二选一） | - | 公司编码（`company_name` 为空时使用） |
| `apiKey` | String | 是 | - | API 密钥，可通过 Header `x-api-key` 或 Query 参数传递 |
| `days` | Integer | 否 | `10` | 查询最近 N 天内有更新的产品 |

### 请求示例

```bash
# 使用公司名称（推荐）
curl -X GET "http://103.236.55.93/api/external/products?company_name=DGAZ&days=10" \
  -H "x-api-key: YOUR_EXPORT_API_KEY"

# 使用公司编码（备选）
curl -X GET "http://103.236.55.93/api/external/products?company_code=CO260620123&days=30" \
  -H "x-api-key: YOUR_EXPORT_API_KEY"
```

### 成功响应

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "exportedAt": "2026-06-25T15:30:00+08:00",
    "total": 2,
    "rows": [
      {
        "id": 8736,
        "name": "Evelyne伊芙琳 16/18 黑色 绸缎内胆包",
        "product_type": "包包",
        "properties": [
          {
            "property_name": "颜色",
            "property_value": "黑色"
          },
          {
            "property_name": "尺寸",
            "property_value": "16/18"
          }
        ],
        "updated_at": "2026-06-24T10:00:00+08:00"
      }
    ]
  }
}
```

### 返回字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `exportedAt` | String | 数据导出时间 |
| `total` | Integer | 返回的产品总数 |
| `rows[].id` | Integer | 产品 ID |
| `rows[].name` | String | 产品名称 |
| `rows[].product_type` | String | 产品种类名称 |
| `rows[].properties` | Array | 属性值列表 |
| `rows[].properties[].property_name` | String | 属性名称 |
| `rows[].properties[].property_value` | String | 属性值 |
| `rows[].updated_at` | String | 产品最后更新时间 |

## 接口三：博主合作单状态同步（外部推送）

### 基本信息

| 项目 | 说明 |
|------|------|
| **接口地址** | `POST /api/external/push` |
| **认证方式** | 无需认证（通过请求体中的公司标识隔离） |
| **功能** | 接收外部系统推送，同步博主合作单的发货状态（切换中国发货 / 创建物流单） |

### 请求参数（JSON Body）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `company_name` | String | **是**（二选一） | 公司名称（优先使用） |
| `company_code` | String | **是**（二选一） | 公司编码（`company_name` 为空时使用） |
| `blogger_cooperation_id` | String | **是** | 博主合作单ID，支持 `"50237"` 或 `"XYJG-COOP-50237"` |
| `switch_to_china_ship` | Boolean | **是** | `true`=切换为中国发货，`false`=创建物流单 |
| `tracking_number` | String | 否 | 物流单号（`switch_to_china_ship=false` 时使用） |

### 请求示例

```bash
# 场景1：切换为中国发货（移除海外发货标签，添加兼职合作单标签）
curl -X POST "http://103.236.55.93/api/external/push" \
  -H "Content-Type: application/json" \
  -d '{
    "company_name": "DGAZ",
    "blogger_cooperation_id": "XYJG-COOP-50237",
    "switch_to_china_ship": true
  }'

# 场景2：创建物流单（登记运单号，移除海外发货和兼职合作单标签）
curl -X POST "http://103.236.55.93/api/external/push" \
  -H "Content-Type: application/json" \
  -d '{
    "company_name": "DGAZ",
    "tracking_number": "RT123456789",
    "blogger_cooperation_id": "XYJG-COOP-50237",
    "switch_to_china_ship": false
  }'

# 使用公司编码（备选）
curl -X POST "http://103.236.55.93/api/external/push" \
  -H "Content-Type: application/json" \
  -d '{
    "company_code": "CO260620123",
    "blogger_cooperation_id": "50237",
    "switch_to_china_ship": true
  }'
```

### 成功响应

#### `switch_to_china_ship = true`（切换为中国发货）

```json
{
  "code": 0,
  "message": "成功切换为中国发货模式",
  "data": {
    "cooperation_id": 50237,
    "tag_changed_to": "DGAZ日本兼职合作单",
    "logistics_created": false
  }
}
```

#### `switch_to_china_ship = false`（创建物流单）

```json
{
  "code": 0,
  "message": "操作成功",
  "data": {
    "cooperation_id": 50237,
    "logistics_id": 123,
    "logistics_created": true,
    "tag_removed": "DGAZ日本海外发货, DGAZ日本兼职合作单",
    "tracking_number": "RT123456789"
  }
}
```

### 业务逻辑说明

| `switch_to_china_ship` | 执行操作 |
|------------------------|---------|
| `true` | 移除"DGAZ日本海外发货"标签 → 添加"DGAZ日本兼职合作单"标签 |
| `false` | 查找"乐天海外仓"物流平台和账号 → 创建物流单并关联到博主合作单 → 移除"DGAZ日本海外发货"和"DGAZ日本兼职合作单"标签（三步为事务，任一步失败回滚） |

## 错误响应

所有接口的错误响应格式统一：

```json
{
  "code": 400,
  "message": "错误描述"
}
```

| code | 说明 |
|------|------|
| 400 | 请求参数错误（如缺少公司标识、ID格式错误、物流单号已存在） |
| 401 | API Key 无效（仅导出接口） |
| 404 | 未找到指定的博主合作单（仅推送接口） |
| 500 | 服务器内部错误 |

## 各语言调用示例

### Python

```python
import requests

BASE_URL = "http://103.236.55.93/api/external"
EXPORT_API_KEY = "YOUR_EXPORT_API_KEY"
COMPANY_NAME = "DGAZ"  # 使用公司名称

# ========== 1. 导出物流单 ==========
def get_logistics(store_name="DGAZ乐天日本", days=7):
    response = requests.get(
        f"{BASE_URL}/logistics/rakuten",
        headers={"x-api-key": EXPORT_API_KEY},
        params={"company_name": COMPANY_NAME, "storeName": store_name, "days": days}
    )
    data = response.json()
    return data["data"]["rows"] if data["code"] == 0 else []

# ========== 2. 导出产品信息 ==========
def get_products(days=10):
    response = requests.get(
        f"{BASE_URL}/products",
        headers={"x-api-key": EXPORT_API_KEY},
        params={"company_name": COMPANY_NAME, "days": days}
    )
    data = response.json()
    return data["data"]["rows"] if data["code"] == 0 else []

# ========== 3. 推送合作单状态 ==========
def push_cooperation_status(cooperation_id, switch_to_china_ship, tracking_number=None):
    payload = {
        "company_name": COMPANY_NAME,
        "blogger_cooperation_id": str(cooperation_id),
        "switch_to_china_ship": switch_to_china_ship
    }
    if tracking_number:
        payload["tracking_number"] = tracking_number
    response = requests.post(f"{BASE_URL}/push", json=payload)
    return response.json()
```

### JavaScript / Node.js

```javascript
const BASE_URL = 'http://103.236.55.93/api/external';
const EXPORT_API_KEY = 'YOUR_EXPORT_API_KEY';
const COMPANY_NAME = 'DGAZ';

// ========== 1. 导出物流单 ==========
async function getLogistics(storeName = 'DGAZ乐天日本', days = 7) {
  const url = new URL(`${BASE_URL}/logistics/rakuten`);
  url.searchParams.set('company_name', COMPANY_NAME);
  url.searchParams.set('storeName', storeName);
  url.searchParams.set('days', days);
  const res = await fetch(url, { headers: { 'x-api-key': EXPORT_API_KEY } });
  const data = await res.json();
  return data.code === 0 ? data.data.rows : [];
}

// ========== 2. 导出产品信息 ==========
async function getProducts(days = 10) {
  const url = new URL(`${BASE_URL}/products`);
  url.searchParams.set('company_name', COMPANY_NAME);
  url.searchParams.set('days', days);
  const res = await fetch(url, { headers: { 'x-api-key': EXPORT_API_KEY } });
  const data = await res.json();
  return data.code === 0 ? data.data.rows : [];
}

// ========== 3. 推送合作单状态 ==========
async function pushCooperationStatus(cooperationId, switchToChinaShip, trackingNumber = null) {
  const payload = {
    company_name: COMPANY_NAME,
    blogger_cooperation_id: String(cooperationId),
    switch_to_china_ship: switchToChinaShip
  };
  if (trackingNumber) payload.tracking_number = trackingNumber;
  const res = await fetch(`${BASE_URL}/push`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(payload)
  });
  return res.json();
}
```

## 注意事项

1. **公司标识**：`company_name`（公司名称）和 `company_code`（公司编码）至少传一个，系统优先使用 `company_name`
2. **API Key**：导出接口（物流单导出、产品导出）需要 API Key，推送接口不需要
3. **数据隔离**：所有接口均按公司隔离数据，只能获取到指定公司的数据
4. **物流单导出**：仅返回已申请到运单号（`logistics_order_id` 不为空）的记录
5. **产品导出**：返回指定天数内有更新的产品，按更新时间倒序排列
6. **推送接口幂等性**：`switch_to_china_ship = false` 时，如果物流单号已存在会返回错误
7. **请求频率**：建议间隔 1 秒以上，避免短时间大量请求
